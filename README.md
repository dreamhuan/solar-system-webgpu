## 数据

天文学家在太阳系内以天文单位（AU）来测量距离。1AU 是地球到太阳的平均距离，大约是 149,597,871 公里。

最常用在测量恒星距离的长度单位是光年，1 光年大约相当于 63,240 天文单位。

### 1. 水星 (Mercury)

- **行星赤道半径**：2,440 千米 (约 0.38 倍地球半径)
- **轨道半长径**：5,790 万千米 (0.39 AU)
- **自转周期**：58.65 倍地球日
- **公转周期**：88.0 倍地球日 (0.24 倍地球年)
